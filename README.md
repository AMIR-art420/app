# پیام‌رسان — نسخه بتا (رایگان)

## ترتیب کار
1. مخزن GitHub **عمومی (Public)** بساز و کل این پوشه را آپلود کن.
2. در Render → New → Blueprint، همین مخزن را انتخاب کن؛ فایل `render.yaml` آماده است و سرویس با نام `payamresan` ساخته می‌شود.
3. اگر Render نام سرویس دیگری ساخت، فقط مقدار `server.url` در `capacitor.config.json` را با آدرس HTTPS همان سرویس عوض کن و commit بزن. مقدار فعلی `https://payamresan.onrender.com` است.
4. در GitHub → Actions → Build APK اجرا می‌شود (یا Run workflow بزن). APK به همان آدرس Render وصل می‌شود و WebSocket را هم به‌صورت امن با `wss://` باز می‌کند.
5. بعد از چند دقیقه APK در بخش Releases است. لینک ثابت دانلود:
   `https://github.com/USER/REPO/releases/latest/download/payamresan-beta.apk`

## محدودیت‌های نسخه رایگان
- سرور رایگان Render بعد از مدتی بی‌استفاده می‌خوابد؛ اولین درخواست بعد از خواب ممکن است چند ده ثانیه دیرتر جواب بدهد. کلاینت برای اتصال WebSocket تلاش مجدد خودکار دارد.
- دیسک رایگان موقت است: با هر ری‌استارت یا دیپلوی دوباره، اتاق‌ها و پیام‌ها پاک می‌شوند. برای بتا قابل قبول است؛ برای ماندگاری باید VPS رایگان/ارزان با دیسک دائمی استفاده شود (SERVER.md).
- APK از نوع debug است؛ کاربران باید «نصب از منابع ناشناس» را روشن کنند.


## حساب کاربری و ظاهر
- قبل از ورود به پیام‌رسان، کاربر باید حساب بسازد یا وارد حساب موجود شود.
- ثبت‌نام شامل نام کاربری، رمز عبور و عکس پروفایل است.
- عکس پروفایل کنار پیام‌های کاربر نمایش داده می‌شود و در تاریخچه‌ی پیام‌ها نیز ذخیره می‌شود.
- از تنظیمات می‌توان عکس پروفایل را تغییر داد.
- پنج تم رنگی در تنظیمات وجود دارد: آبی، مشکی، قرمز، سبز و بنفش.
- رمزهای حساب با `scrypt` هش می‌شوند و خود رمز عبور در کلاینت ذخیره نمی‌شود.
